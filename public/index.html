Save a connected client website

Choose the client’s website, a Google account and its properties. Saved clients appear separately under Connected Clients; you can continue running public audits for other websites.

Connect Google Search Console

Use a property you own or can access. This supplies real Google clicks, queries and average positions. Entering a website alone cannot provide its search traffic.

Checking your Google connection…

Administrator setup (one time)

Create a Google OAuth web application, enable Search Console API, Google Analytics Admin API and Google Analytics Data API, and add this redirect address: https://crawlstudio-pixel-growers.onrender.com/api/google/callback. Add GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET to Render Environment. Google may require test-user registration or app verification. Read the official setup guide.

The team shares this connection. Tokens are encrypted in your database and refresh automatically. Keep the server token key stable.

  1. Click Connect Google account and approve read-only access. Alternatively, your administrator adds a Google access token with Search Console read access in Render Environment. See Google authorization instructions.
  2. Click “Find my properties”, select the website properties, then save the connected client.

Google sign-in refreshes access automatically. If an administrator uses a manual access token instead, it must be renewed when it expires.

Connect Google Analytics 4

Google Analytics is the service; GA4 is its current reporting system. Use the same Google connection above, then select the property whose web stream matches this website.

All reports use the four reporting periods at the top of the workspace. No additional date filters are needed.

What about volume, difficulty and paid traffic?

Search Console does not supply keyword volume, KD, CPC, search intent, SERP features, paid keywords or paid traffic. These stay unavailable until a suitable data source is added. They are never estimated from the crawl.

Running an integration sends the selected content to that provider and may incur API charges. AI reviews are advisory. Provider results appear below; GA4/GSC are separate reports, not automatically joined to crawl URLs.
