CRAWLSTUDIO / ADMINISTRATOR GUIDE

Manage your CrawlStudio workspace.

You are signed in as an administrator. This guide covers saved reports, client connections, audit configuration and workspace management.

← Back to CrawlStudio

1. Open your administrator workspace

Use Administrator login and your existing workspace username and password. Successful sign-in opens Saved Audits directly.

The top of the workspace shows Admin view, and administrator login links are hidden while signed in. Administrators can view the full saved audit history, including public visitor audits. Saved Audits is not available to public visitors. The administrator session lasts eight hours.

2. Review old reports

  1. Open Saved Audits and select Open crawl → beside a website.
  2. Review its Overview or use the technical, performance, on-page and recommendations sections.
  3. Click Print a PDF for the concise overview report.

Each saved entry shows the full audit date and time in your viewing timezone, who started it, and the approximate IP country when available. Older audits show Location not recorded. IP location can reflect a VPN or network provider rather than a physical location.

Click Remove to move an audit out of the saved list. Open Removed audits and click Restore to recover it. Only administrators can remove or restore reports.

To bring in a previously exported crawl, use Saved Audits → Open JSON. Imports are administrator-only.

3. Run and configure an audit

Click New website audit, enter a website and click Get insights. In the dashboard, Crawl configuration controls depth, delay, rendering and advanced checks. Apply configuration before starting the next crawl using the address field and search icon. Keep within this deployment’s page limit.

One crawl runs at a time across visitors and administrators. Connecting a Google property does not unlock a website that blocks the crawler.

4. Understand the audit sections

MenuWhat to use it for
OverviewA summary of URLs checked, technical and on-page findings, public speed results, backlinks and recommended actions.
Technical SEOCheck response codes, crawlability, directives and discovered pages. Click a page in the URL table to inspect its findings.
Website PerformanceSee separate Mobile and Desktop performance scores out of 100, speed measurements and recommendations. Click Run performance test to request new results.
On-page SEOReview titles, descriptions, headings and content findings across the pages checked.
SEO RecommendationsUse the prioritized findings, evidence and recommended fixes to decide what to address first. Confidence labels describe the evidence, not a guaranteed ranking improvement.
Saved AuditsReopen an earlier audit. Public visitors see only audits from their browser session; administrators can review the full workspace history.

5. Connect and manage client websites

  1. Open Connections & Settings.
  2. If Google is available, connect the relevant Google account, then select Find my properties.
  3. Select the client website’s matching Search Console and/or GA4 property, enter its name and website, then save the client.
  4. Open Connected Clients and click Open client overview → for that website.
  5. Choose a reporting period and use Refresh this client’s Google reports to request current data.

Google setup is currently pending. If the connection button is unavailable or setup is required, Google reports cannot load yet. One-time OAuth setup and access to the client’s Google properties are required. A PageSpeed API key does not grant GA4 or Search Console access.

Each connected website keeps separate Google property selections, reports and baseline comparisons. Use New website audit for another prospect without replacing an existing connected client. Available reporting periods are this month, last 3 months, last 6 months and this year.

6. Review integration status and settings

Connections & Settings shows which services are available and how they connect. API keys and deployment settings are configured in Render → Environment, rather than in the website address field. Keep credentials private.

PageSpeed provides mobile and desktop tests without a Google Analytics connection. Crawly supplies source-labelled backlink data. GA4 and Search Console supply permitted, measured client data once connected. Missing data must not be treated as zero.

This free deployment can sleep and does not run scheduled audits. Refresh reports and start crawls manually. Public crawling remains subject to website security restrictions and shared-server capacity.

7. Share reports with clients

Use Print a PDF from an opened audit or connected client dashboard. Public audit PDFs contain the overview, issue counts and available PageSpeed/backlink results. Connected client PDFs also include the available client summary.

Share the downloaded PDF with the client. Your administrator credentials open the shared workspace, including other clients’ reports, and should stay with your team.
