CRAWLSTUDIO / PUBLIC USER GUIDE

Your first website audit.

Enter a website, explore its audit and download a short overview report. No account or Google connection is required for public crawling.

← Back to CrawlStudio

1. Start an audit

  1. Open CrawlStudio, enter the full website address, and click Get insights.
  2. The dashboard opens automatically. Wait for the crawl status to finish; results update as URLs are checked.
  3. Enter the address once. The same crawl supplies all five audit sections.

Public crawls use managed settings and check up to 100 URLs. One crawl can run at a time on this server. If it is busy, try again after the current crawl finishes.

2. Explore your results

MenuWhat to use it for
OverviewA summary of URLs checked, technical and on-page findings, public speed results, backlinks and recommended actions.
Technical SEOCheck response codes, crawlability, directives and discovered pages. Click a page in the URL table to inspect its findings.
Website PerformanceSee separate Mobile and Desktop performance scores out of 100, speed measurements and recommendations. Click Run performance test to request new results.
On-page SEOReview titles, descriptions, headings and content findings across the pages checked.
SEO RecommendationsUse the prioritized findings, evidence and recommended fixes to decide what to address first. Confidence labels describe the evidence, not a guaranteed ranking improvement.

3. Check page speed

Open Website Performance. Mobile and Desktop each have their own overall performance score. The measurements and recommendations explain what affects that tested page.

Use Run performance test if results have not been collected or need refreshing. Tests can take a few minutes. A score describes one tested page, not every page on the website; unavailable data is shown explicitly.

4. Download your report

When the crawl finishes, click the purple Print a PDF button at the top right. It downloads a concise overview with issue counts and highlighted PageSpeed scores. Detailed findings remain in the dashboard.

In Technical SEO, Save JSON, Export CSV and XML sitemap provide additional formats.

5. Audit another website

Click New website audit after the current crawl finishes, or change the address in the dashboard and click the search icon.

Saved Audits is administrator-only. Returning to the homepage starts a fresh visitor session. Download your PDF before leaving; visitors cannot reopen previous reports from a saved library.

Understand incomplete or unavailable results

A security verification screen means the website blocked automated access. It is not an SEO fault or evidence that the site has only one page. PageSpeed and public backlink results may still be available independently.

“Indexable in this crawl” means the checked page meets the recorded crawl criteria. It does not confirm Google indexing. Public audits do not reveal private Google Analytics traffic or Search Console rankings. Backlinks are the provider’s index snapshot.

The free server may take about a minute to wake after inactivity. If a public usage limit is reached, retry after an hour.
