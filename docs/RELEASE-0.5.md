# CrawlStudio 0.5

- Single website welcome screen and Get insights action. No menus on the welcome screen.
- Shared website field and search action in the workspace. Overview, keyword table, search graph, top keywords, date range and comparison.
- Prominent purple Print a PDF action in the top right; existing technical report download retained.
- Bold headings and Graphik local-font support with Arial fallback. No Graphik binaries distributed because webfont rights are unconfirmed.
- Crawl comparison removed from navigation; existing API retained for compatibility.
- Bounded sitemap discovery and www/apex start-redirect resolution. Consistent technical indexability excludes alternate canonicals, blocked/non-HTML/error pages and incomplete analyses.
- Indexable in this crawl is a sample count, not Google index coverage. Kingdom Roofing live test on 2026-10-29 found 12 eligible pages in a 12-page capped crawl. Original one-page saved result was not available to diagnose conclusively.
- Optional Google OAuth sign-in, encrypted refreshable credentials, property selection and Search Console overview data. Administrator OAuth app setup remains required.
- Paid traffic, volume, KD, CPC, intents and SERP-feature metrics require an additional provider and remain unavailable.
- Free hosting page cap and sleeping-service restrictions remain.
